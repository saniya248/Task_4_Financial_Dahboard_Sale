# Task_4_Financial_Sales_Dashboard - Power BI Project

Project Overview

This project focuses on creating an interactive Financial Sales Dashboard using Power BI. The dashboard helps analyze business performance through key metrics such as Sales, Profit, and Gross Sales. It provides a clear and visual representation of data to support better decision-making.

Objective

The main objective of this project is to:

- Monitor overall sales performance.
- Analyze profit trends.
- Track gross sales across different periods.
- Visualize country-wise sales distribution.
- Create an interactive dashboard for data exploration.

Tools Used

- Power BI Desktop
- Financial Sales Dataset
- Microsoft PowerPoint
- GitHub

Dashboard Features

KPI Cards

The dashboard includes KPI cards displaying:

- Total Sales: 119.92M
- Total Profit: 17.14M
- Gross Sales: 129.14M

Monthly Sales and Profit Analysis

A bar chart is used to compare monthly sales and profit performance, helping identify trends and business growth patterns.

Country-wise Sales Distribution

A pie chart visualizes the contribution of different countries to total sales, making it easier to compare market performance.

Interactive Country Filter

A slicer allows users to filter dashboard data based on selected countries for deeper analysis.

Key Insights

- Sales performance varies across different months.
- Profit trends generally follow sales trends.
- Some countries contribute significantly more to overall sales.
- Interactive filtering improves dashboard usability and analysis.
